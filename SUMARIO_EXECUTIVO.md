## 🔄 FLUXO DE PROCESSAMENTO

```
INPUT (Usuário)
    ↓
    ├─→ Vídeo MP4
    ├─→ Áudio MP3 (opcional)
    └─→ Avatar PNG/JPG
    
CONFIGURAÇÃO (Usuário escolhe)
    ↓
    ├─→ Tamanho: 35% (exemplo)
    ├─→ Posição: bottom-right (exemplo)
    └─→ Margem: 15px (exemplo)

PROCESSAMENTO (Backend - ~2-30 minutos)
    ↓
    ├─→ 🎬 Extrair duração
    ├─→ 🎵 Determinar áudio
    ├─→ 📝 Transcrever
    ├─→ 🤖 Gerar avatar
    └─→ 🔗 Merge com FFmpeg
        └─→ Scale: 720 * 0.35 = 252px
        └─→ Overlay: x=W-w-15, y=H-h-15

OUTPUT (Pronto para download)
    ↓
    └─→ Vídeo Final
        ├─→ Avatar redimensionado ✓
        ├─→ Avatar posicionado ✓
        ├─→ Áudio sincronizado ✓
        └─→ Formato MP4 ✓
```
