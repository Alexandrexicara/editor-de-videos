Primeira inicialização no Windows

  1. Baixe ou clone o repositório do Cine Séries integrado.
  2. Abra a pasta multicam no computador conectado às câmeras.
  3. Execute INICIAR-SISTEMA.bat ou instale as dependências com npm install e inicie o painel conforme o README.
  4. Volte a esta página e abra o Estúdio principal. Para controle pelo celular, use o endereço de rede local do computador e a porta indicada no README.
