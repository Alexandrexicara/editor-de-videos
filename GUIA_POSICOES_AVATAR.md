## 💡 Recomendações por Caso de Uso

### 🎤 Apresentação de Produto
```
✓ Posição: top-center
✓ Tamanho: 40%
✓ Margem: 10px
```
**Por quê:** Avatar em destaque no topo, produto em foco abaixo

### 👥 Entrevista Lado a Lado
```
✓ Posição: middle-left ou middle-right
✓ Tamanho: 45%
✓ Margem: 15px
```
**Por quê:** Avatar entrevistador de um lado, convidado do outro

### 📺 Noticiário
```
✓ Posição: top-center
✓ Tamanho: 35%
✓ Margem: 20px
```
**Por quê:** Avatar jornalista em destaque

### 🎨 Criação de Conteúdo
```
✓ Posição: bottom-right (padrão)
✓ Tamanho: 30%
✓ Margem: 15px
```
**Por quê:** Avatar discreto, não interfere no conteúdo

### 📹 Vlog/Tutorial
```
✓ Posição: middle-center
✓ Tamanho: 40%
✓ Margem: 10px
```
**Por quê:** Avatar principal, todo o foco

### 🏆 Marca/Logo
```
✓ Posição: top-right
✓ Tamanho: 25%
✓ Margem: 20px
```
**Por quê:** Avatar marca em local tradicional

### 🎭 Personagem
```
✓ Posição: bottom-left
✓ Tamanho: 50%
✓ Margem: 15px
```
**Por quê:** Personagem apoiador, não principal

## 📐 Combinações Tamanho + Posição

### Tamanho 20% (Muito Pequeno)
```
Melhor com: top-right, top-left, bottom-right
Uso: Logo, marca d'água, assinatura discreta
```

### Tamanho 35% (Pequeno-Médio - PADRÃO)
```
Melhor com: top-center, middle-center, bottom-right

```

### Tamanho 50% (Médio)
```
Melhor com: middle-center, middle-left, middle-right
Uso: Avatar principal, apresentador, entrevistador
```

### Tamanho 60% (Grande - Máximo)
```
Melhor com: top-center, middle-center
Uso: Avatar em foco, máxima atenção
```

## 🎯 Distância da Margem

### Margem 5px (Muito Perto)
```
Avatar fica muito colado na borda
⚠️  Pode parecer desconfortável
```

### Margem 15px (Padrão)
```
✓ Espaço confortável
✓ Avatar bem posicionado
✓ Não parece apertado
```

### Margem 30px (Longe)
```
✓ Avatar afastado da borda
✓ Mais respiro visual
✓ Parece mais profissional
```

### Margem 50px (Muito Longe)
```
✓ Espaço máximo
✓ Avatar bem separado
⚠️  Pode deixar espaço vazio demais
```

## 🎨 Dicas de Design

### ✅ Boas Práticas
- ✓ Deixar margem de 15-20px para não parecer colado
- ✓ Usar tamanho que não cubra conteúdo importante
- ✓ Testar com vídeo real antes de finalizar
- ✓ Considerar o formato do avatar (quadrado, retângulo, etc)
- ✓ Garantir que avatar tenha fundo transparente ou contraste

### ❌ Evitar
- ✗ Avatar muito grande cobrindo todo o conteúdo
- ✗ Avatar muito pequeno, irrelevante
- ✗ Margens desiguais (5px de um lado, 50px do outro)
- ✗ Posições inconsistentes entre vídeos da mesma série
- ✗ Avatar com qualidade ruim ou borrada

## 🔄 Mudando Posição Dinamicamente

**Importante:** Se quiser mudar a posição do avatar:
1. Volte para http://localhost:3001
2. Escolha nova posição
3. Deixe outros configurações (tamanho, margem)
4. Upload os mesmos arquivos (já serão salvos)
5. Clique PROCESSAR novamente

**Resultado:** Novo vídeo com avatar em posição diferente

## 📞 Suporte

Se tiver dúvidas sobre qual posição escolher:

1. **Conte-nos sobre seu vídeo:**
   - É apresentação? Tutorial? Vlog? Entrevista?
   - Avatar é principal ou secundário?
   - Qual é o conteúdo principal?

2. **Recomendamos:**
   - Teste a posição padrão (bottom-right) primeiro
   - Mude uma coisa por vez
   - Veja o resultado antes de mudanças maiores

3. **Dicas finais:**
   - Consistência é importante (mesma posição em série)
   - Profissionalismo: margens iguais (não 5px + 30px)
   - Teste com público-alvo (qual tamanho se vê bem?)
